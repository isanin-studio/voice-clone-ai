# voice-clone — синтез речи вашим голосом (локально, RTX 5070 Ti)

Записать 20 секунд своего голоса → писать текст → получать WAV своим голосом.
Всё считается на GPU, наружу ничего не уходит.

## Стек

| Компонент | Выбор |
|---|---|
| Модель | XTTS-v2 (zero-shot клонирование, 17 языков, русский) |
| Рантайм | `coqui-tts` (поддерживаемый форк Coqui TTS) |
| PyTorch | cu128 — обязательно для Blackwell (sm_120) |
| VRAM | ~4 ГБ из 16 |

Лицензия модели — Coqui Public Model License: личное и исследовательское
использование. Для коммерции — F5-TTS (MIT), см. «Дальше».

## Установка

```powershell
E:\development\voice-clone\setup.ps1
```

Скрипт создаёт `.venv`, ставит torch cu128 и печатает имя видеокарты.
Если `cuda False` — Python не 3.11/3.12 либо драйвер старше 570.

## Использование

1. Список микрофонов:

```powershell
.\.venv\Scripts\python.exe src\record.py --list
```

2а. Конвертация готовых записей (ogg, m4a, mp3, mp4) в референсы:

```powershell
.\.venv\Scripts\python.exe src\prepare.py C:\Users\<user>\Desktop\*.ogg
```

2б. Либо запись напрямую с микрофона:

```powershell
.\.venv\Scripts\python.exe src\record.py -s 20 -o data/voice/ref.wav
```

3. Синтез:

```powershell
.\.venv\Scripts\python.exe src\speak.py "Текст, который надо озвучить."
```

Из файла и с другим темпом:

```powershell
.\.venv\Scripts\python.exe src\speak.py -f data/text.txt --speed 1.1 -o out/report.wav
```

Первый запуск скачивает модель (~1.8 ГБ) в
`C:\Users\<user>\AppData\Local\tts`.

## Качество референса

- 15–25 секунд; короче — теряется тембр, длиннее — прироста нет.
- Несколько файлов в `data/voice/` усредняются: 3 записи по 15 с дают
  стабильнее результат, чем одна.
- Без музыки, эха и обрезанных слов на краях. Пик не в клиппинг.
- Интонация референса переносится на синтез: читать нейтрально.

## Ударения

XTTS ошибается на омографах. Ставьте `+` перед ударной гласной —
скрипты переводят это в комбинирующий акут U+0301, который модель
воспринимает:

```
Я открыл зам+ок своим ключом.
В мешке была мук+а.
```

Проверено экспериментально: акут даёт верное ударение без искажений.
Заглавная буква (`замОк`) тоже смещает ударение, но ускоряет темп;
удвоение гласной звучит неестественно. Подобрать нотацию для своего
слова: `srcccent.py <слово> <номер гласной>`.

## Грабли

| Симптом | Причина | Фикс |
|---|---|---|
| `no kernel image is available` | torch не cu128 | переставить torch с индекса cu128 |
| `WeightsUnpickler error` | torch≥2.6 `weights_only` | уже обойдено в `src/speak.py` |
| `torchcodec required` | torch>=2.9 | ставить `coqui-tts[codec]` |
| `libtorchcodec_core*.dll` не грузится | нет shared FFmpeg | `winget install BtbN.FFmpeg.GPL.Shared.7.1` |
| DLL есть, но не видны | Python 3.8+ игнорирует PATH | обойдено в `src/ffmpeg_dlls.py` |
| Металлический голос | тихий/шумный референс | перезаписать, следить за пиком |
| Неверные ударения | XTTS не расставляет их | ставить `+` перед ударной гласной |
