# Путеводитель: voice-clone

Автономная инструкция: достаточно этой папки, исходников и перечисленных защищённых копий. История чатов и центральный каталог не требуются.

[Восстановление](RECOVERY.md) · [Карта файлов и зависимостей](PROJECT_MAP.json)

## Назначение

По [README.md](README.md): Записать 20 секунд своего голоса → писать текст → получать WAV своим голосом. Всё считается на GPU, наружу ничего не уходит.

Обнаруженные языки: PowerShell, Python.
