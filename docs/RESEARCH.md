# Исследование: управление ударением в XTTS-v2 (русский)

Дата: 2026-08-24
Стенд: RTX 5070 Ti 16 ГБ (Blackwell, sm_120), Windows 11, Python 3.12,
torch 2.11.0+cu128, coqui-tts 0.27.5, XTTS-v2.

## Проблема

XTTS-v2 не имеет интерфейса для указания ударения. Русские омографы
(`за́мок` / `замо́к`, `му́ка` / `мука́`) модель разрешает по контексту
и регулярно ошибается. Документация приёма не описывает.

## Гипотезы

| Код | Нотация | Обоснование |
|---|---|---|
| `plain` | `замок` | контроль, поведение по умолчанию |
| `acute` | `замо́к` | U+0301 мог встречаться в обучающих текстах |
| `upper` | `замОк` | смена регистра меняет токенизацию BPE |
| `doubled` | `замоок` | удлинение гласной как суррогат ударения |

## Методика

1. Референс голоса: три записи, 105 с суммарно, 22.05 кГц моно.
2. Единая фраза-контекст: «Я открыл {} своим ключом.»
   Контекст семантически требует ударения на второй слог.
3. Четыре синтеза, различающихся только написанием целевого слова.
4. Слепая оценка на слух носителем языка.

Инструмент: `src/accent.py <слово> <номер ударной гласной>`.

## Результаты

| Нотация | Ударение | Темп | Артефакты | Вывод |
|---|---|---|---|---|
| `plain` | `зА-мок` — неверно | норма | нет | непригодно |
| `acute` | `за-мО́к` — **верно** | норма | нет | **рабочий приём** |
| `upper` | `за-мО́к` — верно | **ускорен** | нет | пригодно с оговоркой |
| `doubled` | смещено | растянут | неестественная долгота | непригодно |

## Вывод

Комбинирующий акут U+0301 после ударной гласной надёжно смещает
ударение без побочных эффектов на темп и тембр. Модель, очевидно,
видела размеченные ударением тексты в обучающем корпусе.

Смена регистра также срабатывает, но заглавная буква меняет
токенизацию всего слова, что укорачивает его произнесение — для
длинных фраз даёт рваный ритм. Как запасной вариант приемлемо.

## Реализация

Набор U+0301 с клавиатуры неудобен, поэтому введена нотация Silero:
`+` перед ударной гласной. Преобразование — `src/accents.py`,
применяется автоматически в `speak.py` и `voiceprint.py`.

```
Я открыл зам+ок своим ключом.  ->  Я открыл замо́к своим ключом.
```

## Ограничения

- Проверено на одном слове и одном голосе. Выборка не позволяет
  утверждать устойчивость на всех омографах.
- Референсы получены из голосовых Telegram (Opus, низкий битрейт),
  верхние частоты срезаны. На студийном материале поведение может
  отличаться.
- Оценка субъективная, без измерения F0 и длительностей слогов.

## Следующие шаги

1. Прогнать список из 30–50 частотных омографов, посчитать долю
   верных ударений — получить количественную оценку.
2. Сравнить с F5-TTS + RUAccent, где ударения расставляются словарём
   на этапе g2p: там управление явное, а не эмпирическое.
3. Повторить эксперимент на референсах с DJI Mic (48 кГц) —
   проверить, влияет ли качество источника на разбор нотации.

# Приложение: грабли стека на Blackwell

Развёртывание XTTS-v2 на RTX 5070 Ti потребовало пяти обходов.
Все закреплены в `setup.ps1` и коде.

| Симптом | Причина | Решение |
|---|---|---|
| `no kernel image is available` | sm_120 не поддержан сборками cu121/cu124 | torch с индекса cu128 |
| `cannot import name 'isin_mps_friendly'` | transformers 5.x убрал функцию, coqui-tts её ждёт | закрепить `transformers<5` |
| `WeightsUnpickler error` | torch>=2.6 грузит чекпойнты с `weights_only=True` | подмена `torch.load` в `speak.py` |
| `torchcodec library is required` | torch>=2.9 вынес аудио-IO во внешний пакет | `coqui-tts[codec]` |
| `libtorchcodec_core4.dll` не грузится | нужны shared-библиотеки FFmpeg; статическая сборка и версия 8+ не подходят | `BtbN.FFmpeg.GPL.Shared.7.1` |
| DLL установлены, но не найдены | Python 3.8+ не ищет зависимости расширений в PATH | `os.add_dll_directory` в `src/ffmpeg_dlls.py` |

## Расход VRAM

| Режим | VRAM | Комментарий |
|---|---|---|
| Инференс XTTS-v2 | ~4 ГБ | текущий |
| Файнтюн XTTS на своём голосе | 10–14 ГБ | не пробован, следующий этап |

Zero-shot инференс не нагружает карту 16 ГБ и на четверть. Ресурс
видеопамяти окупается только при дообучении на собственном корпусе
(30–60 минут речи), что и является следующим шагом по качеству.
